# Ivy Generator — Geometry Nodes

레퍼런스 `Ivy_Generator_Blender_3.0`의 노드 구조를 그대로 재구성한 아이비 제너레이터다. 표면을 따라 줄기를 키우지 않는다. 나선을 대상 표면에 투영해 띠를 만들고, 그 위에 줄기와 잎이 함께 있는 잎가지 메시를 흩뿌린다.

## 사용

1. Object Mode에서 감쌀 메시를 선택한다. 여러 개를 선택해도 된다.
2. 시작할 곳에 3D 커서를 놓는다.
3. N 패널 → Create → Ivy Generator → **아이비 생성**.
4. 생성된 Ivy를 선택하고 값을 바꾼다.

생성할 때 값은 대상 크기에 맞춰 잡힌다.

| 조절값 | 의미 |
| --- | --- |
| 대상 | 아이비가 감쌀 메시들. 컬렉션을 직접 고를 수도 있다 |
| 퍼짐 반경 | 시작점을 중심으로 한 나선 반경 |
| 높이 | 나선 높이. 시작점이 가운데다 |
| 감김 수 | 나선 회전 수 |
| 띠 폭 | 잎가지를 뿌리는 띠의 폭 |
| 잎 밀도 | 덮는 정도. 1이 가장 촘촘하다 |
| 잎 크기 | 잎가지 크기. 간격도 함께 맞춰진다 |
| 랜덤 시드 | 같은 나선에서 잎가지 배치만 바꾼다 |

- **시작점 추가:** 3D 커서를 옮기고 **3D 커서에 시작점 추가**를 누른다. Edit Mode에서 Ivy 메시의 정점을 직접 옮기거나 추가해도 된다. 정점 하나가 나선 하나다.
- **대상 교체:** 새 대상을 선택한 뒤 Ivy를 Shift로 마지막에 선택하고 **선택 메시로 대상 교체**를 누른다.
- **잎 바꾸기:** `Ivy_Instance` 컬렉션의 메시를 바꾸면 된다.

## 잎가지 원본

새 파일에서 처음 생성할 때 다운로드 폴더의 `Ivy_Generator_Blender_3.0_NodeTree.blend`에서 `Ivy_Instance` 컬렉션을 읽어 온다. 원본 파일은 수정하지 않으며 애드온 저장소에 복사하지 않는다. 위치를 옮겼다면 애드온 환경설정에서 파일을 지정한다. 이미 생성해 저장한 파일은 애드온과 원본 없이도 평가된다.

## 레퍼런스와 다른 점

- 레퍼런스의 띠는 커브의 비틀림을 그대로 따라서, 평평한 벽에서는 띠가 옆으로 서며 폭이 0이 되는 구간이 생긴다. 그 결과 잎이 줄무늬로 끊긴다. 여기서는 띠의 폭 방향을 항상 표면을 따라가게 고정했다.
- 잎가지의 띄움 방향과 정렬은 띠 면 대신 대상 표면의 법선을 쓴다. 레퍼런스에서는 일부 잎가지가 표면 안쪽으로 들어갔다.
- 나선은 레퍼런스와 같은 Z축 방향이다. 얇은 벽이면 뒤쪽 반은 뒷면에 붙는다.
- 0.2 이하로 만든 아이비는 파일에 저장된 노드로 계속 평가되지만, 패널에서 조절할 수 없다.
